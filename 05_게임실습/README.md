# 제천10경 탐험대

`완성게임/index.html`을 실행한다. 로컬 파일 정책으로 엔진 또는 이미지가 차단되면 프로젝트 루트에서 `python -m http.server 8765 --bind 127.0.0.1`을 실행하고 `http://127.0.0.1:8765/05_게임실습/완성게임/index.html`로 접속한다. 서버 중지는 해당 터미널에서 Ctrl+C이다. 다른 서버가 이미 같은 포트를 사용하면 8766 등으로 바꾼다.

방향키 또는 A/D 이동, Space 점프, P 일시정지. 화면 버튼으로도 조작 가능하다. 게임 화면을 먼저 클릭한다. 창을 벗어나면 자동 일시정지한다. 수업 중 프롬프트를 작성하고 돌아오면 계속하기를 누른다.

단계 1은 도형의 이동·점프, 단계 2는 도형과 장애물, 단계 3은 캐릭터 원본·점수·완료 상태를 사용한다. 단계별 실행 진입점은 서로 다르며 공통 `rules.js`와 `game.js`를 공유한다. 복습 때는 해당 기능 부분을 읽고 수정한 사본으로 비교한다.

`rules.js`: 좌표·중력·점프·충돌·점수·종료 규칙. `game.js`: Phaser 화면과 입력. `assets.js`: 원본 자산 목록. `style.css`: 선택 화면. 엔진은 vendor에 고정 버전으로 포함하며 라이선스를 함께 둔다.

캐릭터 JPG는 파일명만 영문으로 바꿔 바이트 그대로 복사했다. 원본 격자 배경을 제거하지 않았고, 움직임은 원본 이미지 카드 전체의 위치 이동으로 구현했다. 원작 캐릭터를 도트화하거나 자세별 이미지로 변형한 스프라이트가 아니다. 도트 배경과 장애물은 본 예제에서 새로 작성했다. 관광지의 정확한 지형이나 캐릭터 대응 관계를 재현하지 않았다. 출처와 조건은 `자산출처.json`에 기록했다. 외부 공개·상업 사용·원본 변형을 승인받았다는 의미는 아니다.
