2. 공식 Windows 설치기를 실행함

irm https://claude.ai/install.ps1 | iex

새 터미널에서 버전을 확인하고 프로젝트 폴더에서 실행함.

claude --version
claude

명령을 찾지 못하면 설치 폴더를 사용자 PATH에 추가하거나 다음과 같이 전체 경로로 실행함.

& "$env:USERPROFILE\.local\bin\claude.exe" --version
& "$env:USERPROFILE\.local\bin\claude.exe"
README.md와 hello.html을 읽고 각각의 역할과
초보자가 확인할 항목을 세 가지로 설명해줘.
파일은 수정하지 말아줘.

실제 네이티브 설치 버전은 2.1.322임. 기존 npm 설치본이 먼저 실행될 수 있으므로 명령 경로와 버전을 함께 확인함. 제작 환경의 Get-FileHash 오류는 현재 설치 프로세스의 Windows 모듈 검색 경로를 복구해 해결함. 사용자 PATH는 임의로 변경하지 않았음.

고등학생이 만드는 횡스크롤 게임임.
캐릭터 선택·이동·점프·충돌·다시 시작을 포함해줘.
원본 이미지 이용 조건과 검증 기준을 명시해줘.

설치와 실제 Codex 요청을 실행했음. 결과 프롬프트는 입력 조건과 검증 항목을 포함함.

4. 지정 HWPX 스킬과 원본 양식을 사용함

npx.cmd skills add Canine89/gonggong_hwpxskills --skill hwpx --agent codex --agent claude-code --yes

양식 선택 → 원본 복사 → 텍스트 조사 → 내용 치환 → 구조 검증 → 한글 열림 → PDF 확인 순서로 진행함.

$hwpx 스킬을 사용해 보고서를 작성해줘.
report-template.hwpx의 표지·목차·본문 서식을 유지해줘.
주제는 AI 실습 자료 제작 보고서임.
확인된 내용만 쓰고 원본을 덮어쓰지 말아줘.
HWPX 구조·한글 열림·쪽수와 배치를 검증해줘.

위 입력은 재사용 예시임. 이번 문서는 현재 에이전트가 HWPX 스킬 지침에 따라 실제 Python 치환 도구로 작성했음. CLI 자율 생성 결과로 표시하지 않음.

원본의 표·서식을 유지하고 목차를 실제 본문 4개 항목과 본문 쪽수 1–2에 맞춤. 원본의 로고도 유지함. 한글과 PDF 모두 4쪽이며 전체 쪽 배치를 확인함.

원본 양식 · 완성 HWPX · 검증 PDF · 치환 매핑
