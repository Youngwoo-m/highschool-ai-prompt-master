4차시 체험형

설치 완료된 교사 PC와 실행 예제를 사용한다. 1차시 두 앱 체험과 요청 작성, 2차시 작은 웹페이지와 게임 예제 수정, 3차시 캐릭터 선택·게임 시험, 4차시 보고서 작성·발표로 구성한다. 모든 도구를 직접 설치하는 과정은 이 운영안에 포함하지 않는다.

6시간 교사 연수형

실습 6개 묶음 × 50분 = 300분, 휴식·정리 60분으로 360분을 구성한다. ①앱 체험·Codex ②Claude Code·지침 파일 ③스킬·플러그인·MCP ④프롬프트·find-skills ⑤게임 개발·검증 ⑥HWPX·평가 계획 순서다. 설치 준비가 안 된 경우 게임 확장을 줄이고 준비 시간을 확보한다.

준비 환경

  • 교사용 Windows 11 PC, 브라우저, 인터넷, 이용 가능한 AI 계정, Python과 Node.js. 한글 문서 열람이 가능한 프로그램.
  • 학생은 계정·연령·학교 정책에 맞는 경로만 사용한다. Claude 개인용 서비스가 허용되지 않는 학생은 가입 대신 교사 시연과 요청문 활동을 한다.
  • API 키·로그인 정보를 교재에 배포하지 않는다. 무료 정적 예제 실행과 AI 서비스 사용 비용을 구분한다.
  • 실제 수업 전 학교 네트워크에서 공식 사이트 접근, npm·Python 설치 정책, 로컬 서버 포트와 문서 열림을 확인한다.
  • 오프라인 대안: HTML 교재·캡처·로컬 게임·HWPX/PDF를 제공하고 요청문 설계와 결과 분석을 진행한다. 새로운 AI 응답까지 오프라인에서 가능하다고 설명하지 않는다.
