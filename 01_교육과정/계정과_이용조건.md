# 계정·연령·비용 확인

2026-11-10 공식 약관·설치 안내를 확인했다. 수업 실시 전 변경 여부와 학교 정책을 다시 확인한다.

- [OpenAI 개인용 이용약관](https://openai.com/policies/terms-of-use/): 최소 13세 또는 국가에서 요구하는 연령, 18세 미만 보호자 허락. 제품별 이용 가능성과 학교 계정 조건을 추가 확인한다.
- [Anthropic 개인용 이용약관](https://www.anthropic.com/legal/consumer-terms): 최소 18세 또는 해당 지역의 더 높은 최소 연령. 기본 고교 수업은 Claude Code 교사 시연으로 설계한다. 교사 계정을 학생과 공유하지 않는다.
- [Claude Code 시작 안내](https://code.claude.com/docs/en/quickstart): 지원 구독·Console/API 등 인증 경로에 따라 비용이 달라진다. 무료 채팅 계정만 있으면 모든 코딩 기능이 된다고 설명하지 않는다.
- Skills CLI, Phaser, Python 등 로컬 도구의 설치 비용과 AI 서비스 이용료는 별개다. 교재에는 특정 요금제 가격을 고정하여 적지 않았다.
