② 대상과 기능을 명시함

프로젝트의 prompt-master 스킬을 사용해서 Codex에 입력할 게임 개발 프롬프트를 작성해줘. 대상은 고등학교 학생이며 Windows 브라우저에서 실행하는 횡스크롤 게임이다. 준비 자료는 제천10경 캐릭터 원본 JPG 10개다. 원본을 변형하지 않고 전체 이미지 카드로 표시하며 경 번호를 고유 ID로 사용한다. 캐릭터 선택, 좌우 이동, 지상 점프, 장애물 충돌, 체력 3, 점수, 일시정지, 종료와 다시 시작이 필요하다. 목적·입력 자료·작업 범위·기능·완료 기준을 명확히 한 복사 가능한 프롬프트 하나를 작성해줘. 게임이나 다른 파일은 만들지 말고 프롬프트만 작성해줘. 숨겨진 추론 과정은 출력하지 마.

③ 실제 출력에서 조건을 확인함

별도 프로젝트에서 Codex가 설치된 Prompt Master 스킬을 읽고 작성한 실제 응답임. 아래 출력과 기존 완성 게임은 별도 결과물이므로 설계값을 대조한 뒤 활용함.

```text
고등학교 학생이 실행하고 코드를 이해할 수 있는 제천10경 캐릭터 횡스크롤 게임을 개발해줘. 아래 목적, 입력 자료, 작업 범위, 기능, 완료 기준에 따라 구현과 검증까지 수행해줘.

[목적]
- Windows의 Chrome 또는 Edge 브라우저에서 실행하는 간단한 2D 횡스크롤 게임을 만든다.
- 학생이 캐릭터를 선택하고 좌우 이동과 점프로 장애물을 피하면서 점수를 얻도록 한다.
- 학생이 수정하기 쉽도록 HTML, CSS, JavaScript를 사용하고, 주요 게임 규칙과 설정값에 간단한 한국어 주석을 작성한다.

[입력 자료]
- 준비 자료는 제천10경 캐릭터 원본 JPG 10개다.
- 먼저 프로젝트에서 해당 파일과 파일명에 포함된 경 번호를 확인한다. 경 번호 1~10을 캐릭터의 고유 ID로 사용하며, 파일 정렬 순서나 배열 인덱스를 ID로 사용하지 않는다.
- 각 캐릭터의 ID와 실제 이미지 경로를 명시적으로 연결한다. 캐릭터 이름은 자료에서 확인되는 경우에만 사용한다.
- 이미지가 누락되거나 경 번호가 중복되거나 파일과 경 번호의 대응이 불명확하면, 임의로 추정하거나 대체 이미지를 만들지 말고 필요한 사항을 질문한다.

[원본 이미지 보존]
- 원본 JPG를 수정하거나 덮어쓰거나 이름을 변경하지 않는다.
- 캐릭터 선택 화면과 게임 화면 모두에서 원본의 전체 이미지가 보이는 직사각형 카드로 표시한다.
- 표시 크기만 원본 비율에 맞춰 조절한다. 카드 내부에 여백을 허용하고, 이미지가 잘리지 않도록 object-fit: contain 또는 이에 해당하는 방식을 사용한다.
- 자르기, 배경 제거, 색상 변경, 필터, 좌우 반전, 이미지 위에 직접 그리기, 스프라이트 변환을 하지 않는다. 이동 방향이 바뀌어도 이미지를 뒤집지 않는다.
- 선택 테두리, 경 번호, 체력 등은 이미지 바깥의 별도 UI로 표시한다.

[작업 범위]
- 기존 프로젝트 구조를 확인한 후 게임에 필요한 파일만 별도 폴더에 작성한다. 기존 파일은 보존한다.
- 별도 설치나 빌드 없이 index.html을 브라우저에서 열어 실행할 수 있게 한다. 외부 CDN, 외부 API, 서버, 로그인 기능은 사용하지 않는다.
- 단일 스테이지의 횡스크롤 게임으로 구현한다. 캐릭터는 화면 안에서 좌우로 이동하고, 배경 또는 장애물은 오른쪽에서 왼쪽으로 흐르도록 한다.
- 배경과 장애물은 단순한 도형으로 구현하고, 캐릭터별 능력 차이는 두지 않는다.
- 모바일 대응, 온라인 순위, 저장 기능, 추가 스테이지, 사운드 등 요청하지 않은 기능은 추가하지 않는다.

[필수 기능]
1. 캐릭터 선택
   - 원본 JPG 10개를 경 번호와 함께 전체 이미지 카드로 표시한다.
   - 선택한 카드가 명확히 구분되도록 하고, 캐릭터 선택 후 시작 버튼으로 게임에 진입한다.
   - 선택한 캐릭터의 고유 ID와 이미지가 실제 플레이에 일치하게 적용된다.

2. 좌우 이동과 지상 점프
   - 방향키 ←/→ 또는 A/D로 좌우 이동한다.
   - Space로 점프하며, 지면에 있을 때만 점프할 수 있다. 공중에서 추가 점프는 허용하지 않는다.
   - 중력과 착지를 구현하고, 캐릭터가 화면 밖으로 벗어나지 않게 한다.
   - 게임 조작 중 방향키와 Space로 페이지가 스크롤되지 않게 한다.

3. 장애물과 충돌
   - 장애물이 오른쪽에서 등장하여 왼쪽으로 이동한다.
   - 장애물의 크기와 간격은 기본 점프로 회피할 수 있는 범위로 설정한다.
   - 캐릭터 카드와 장애물의 직사각형 영역을 기준으로 충돌을 판정한다.
   - 체력은 3으로 시작하고, 충돌하면 1씩 감소한다.
   - 충돌 후 약 1초의 무적 시간을 두고 같은 장애물에서는 중복 피해를 받지 않게 한다. 피해 상태는 카드 테두리나 별도 표시로 알린다.
   - 체력이 0이 되면 게임 오버 화면으로 전환하고 진행을 멈춘다.

4. 점수
   - 장애물을 충돌 없이 완전히 통과하면 장애물당 10점을 한 번만 부여한다.
   - 현재 점수를 플레이 화면에 표시하고, 게임 오버 또는 종료 화면에 최종 점수를 표시한다.

5. 일시정지와 재개
   - 일시정지 버튼과 P 키로 정지하거나 재개한다.
   - 일시정지 중에는 캐릭터, 장애물, 물리 계산, 점수와 무적 시간 등 게임 내 시간의 진행을 모두 멈춘다.
   - 브라우저 탭 전환이나 창 포커스 상실 시 자동으로 일시정지하고, 입력 상태를 초기화한다. 사용자가 재개하기 전에는 진행하지 않는다.

6. 종료와 다시 시작
   - 종료 버튼을 누르면 현재 플레이를 끝내고 최종 점수, 다시 시작, 캐릭터 선택으로 돌아가기 버튼을 표시한다. 종료는 브라우저 창을 닫는 동작이 아니다.
   - 다시 시작은 현재 선택한 캐릭터로 새 게임을 시작한다.
   - 다시 시작할 때 체력 3, 점수 0, 시작 위치, 장애물, 입력 상태, 타이머와 무적 상태를 모두 초기화한다.
   - 재시작을 반복해도 애니메이션 루프나 이벤트 처리가 중복되지 않게 한다.

[화면과 코드]
- 안내 문구와 버튼은 한국어로 작성하고, 조작법을 화면에 표시한다.
- 캐릭터 선택, 플레이, 일시정지, 게임 오버, 종료 상태를 명확히 구분한다.
- 체력, 점수, 선택 캐릭터의 경 번호를 쉽게 확인할 수 있게 한다.
- 이동 속도, 점프 세기, 중력, 장애물 간격, 무적 시간 등 학생이 바꿔볼 설정값을 한곳에 모은다.
- 프레임 경과 시간을 반영하여 이동과 물리 계산을 처리하고, 정지 후 재개할 때 갑자기 위치가 뛰지 않게 한다.
- 이미지 로딩 실패 시 해당 경 번호와 오류를 화면에 표시한다.

[완료 기준]
- Windows의 Chrome 또는 Edge에서 index.html을 열면 외부 서비스 없이 캐릭터 선택 화면이 표시된다.
- 경 번호 1~10이 고유 ID로 연결되고, 10개 이미지가 선택 화면과 플레이 화면에서 잘림이나 변형 없이 표시된다.
- 원본 JPG 10개의 파일 내용이 작업 전후 동일하다.
- 좌우 이동, 화면 경계 제한, 지상 점프, 공중 추가 점프 방지와 착지가 정상 작동한다.
- 충돌 시 체력이 3→2→1→0으로 감소하고, 무적 시간과 동일 장애물의 중복 피해 방지가 작동한다.
- 충돌 없이 통과한 장애물마다 정확히 10점이 한 번만 부여된다.
- 일시정지 중 모든 게임 진행이 멈추고 재개 시 자연스럽게 이어진다.
- 탭 전환 후 자동 정지되며, 복귀 후 이동 키가 계속 눌린 상태로 남지 않는다.
- 게임 오버와 종료 후 다시 시작하거나 캐릭터 선택으로 돌아갈 수 있다.
- 다시 시작을 3회 이상 반복해도 체력·점수·장애물이 초기화되고 게임 속도가 중복 증가하지 않는다.
- 실행 중 이미지 누락, 처리되지 않은 JavaScript 오류, 불필요한 외부 네트워크 요청이 없다.

[검증과 최종 보고]
- 가능한 환경에서 실제 브라우저로 실행하여 완료 기준을 확인하고 문제를 수정한다.
- 실제로 실행하지 못한 항목은 검증 완료로 표시하지 말고 미검증 항목과 이유를 명시한다.
- 최종 답변에는 생성한 파일 위치, 실행 방법, 조작법, 검증 결과와 남은 제한 사항만 간결하게 작성한다.
- 계획 제시에 그치지 말고 실제 구현과 가능한 검증까지 완료한다.
- 숨겨진 추론 과정은 출력하지 않는다.
```
