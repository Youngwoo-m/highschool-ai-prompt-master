개념과 활용 상황 예시를 펼침
서브에이전트(Subagent)
주 에이전트가 맡긴 일부 작업을 역할과 도구 권한의 범위 안에서 수행하는 보조 에이전트임. 별도 작업 맥락에서 분석하고 결과를 주 에이전트에 반환함. 독립적인 작업은 병렬로 분담할 수 있고 순차 검토에도 활용할 수 있음.
훅(Hooks)
세션 시작, 도구 사용 전후, 작업 종료 같은 사건·시점에 등록한 동작을 실행하는 확장 기능임. 이 페이지의 검사 예시는 명령형 훅을 기준으로 함. 지원하는 이벤트·훅 종류·설정 형식은 제품별로 확인함.

활용 예시 1: 게임 검토 역할을 맡김

주 에이전트 → 게임 검토 서브에이전트 → 검토 결과 반환 → 주 에이전트가 수정 판단

게임 개발과 검토 역할을 나눔. 검토 담당은 점프·장애물 충돌·체력 0 종료·재시작을 확인하고 문제 위치와 근거를 반환함. 검토 담당의 파일 수정을 허용할지는 별도로 정함.

게임 검토 담당 서브에이전트에게 점프·충돌·종료·재시작을 검토하게 해줘.
파일을 수정하지 말고 문제 위치, 재현 방법, 확인 근거를 정리해줘.
주 에이전트는 검토 결과를 모아 수정 우선순위를 정해줘.

활용 예시 2: 보고서 검토 역할을 맡김

원자료와 보고서의 출처, 빠진 항목, 지정 양식 준수 여부를 검토 담당에게 맡김. 보고서 작성 담당과 검토 담당의 역할을 나누고 주 에이전트가 결과를 종합함.

활용 예시 3: 코드 수정 뒤 검사함

대상 파일 수정 → PostToolUse → 파일 종류 확인 → 형식 검사기 실행 → 오류 알림

설정한 Write·Edit 등 대상 도구의 성공 후 파일 유형에 맞는 검사기를 실행하도록 구성함. 이벤트 이름이 같더라도 제품별 도구 이름과 입력 형식이 같다고 가정하지 않음.

활용 예시 4: HWPX 저장 뒤 검사함

HWPX 생성·저장 도구 호출 완료 → 결과 파일 확인 → 패키지 구조 검사 → 오류 알림

HWPX 파일을 만든 도구 호출 뒤 해당 결과 파일을 검사하도록 조건을 설정할 수 있음. ZIP/XML 구조 검사는 한글에서의 표 배치·줄바꿈 확인과 구분함. 구조 검사를 통과했더라도 실제 한글 열림·쪽수·시각적 검수는 별도로 수행함.

위 내용은 교육자료에 적용할 수 있는 활용 예시임. 이번 페이지 추가 과정에서 새 서브에이전트를 기동하거나 프로젝트에 훅을 등록하지 않았음.
