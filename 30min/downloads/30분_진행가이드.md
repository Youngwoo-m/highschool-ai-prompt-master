# 교사와 학생을 위한 AI 활용: 30분 진행 가이드

14장, 영상 및 짧은 참여를 포함한 운영안임. 실제 청중 앞 30분 리허설을 완료했다는 의미는 아님. 장별 시간을 지키고 설치 전체 실습은 웹 교재로 연결함.

## 01. AI로 만든 룰렛을 체험함 / 0~2분

학교 행사 뒤풀이 메뉴를 고르는 상황을 제시함. 무엇을 입력하고 어떤 결과를 받는지 먼저 관찰하도록 안내함.

룰렛 영상에서 후보와 결과가 어떻게 바뀌는지 보여줌. 결과 화면을 만들었다는 사실과 무작위 선택 규칙이 올바르게 구현되었다는 사실은 구분함.

추가하고 싶은 메뉴 한 가지를 받아 입력 조건으로 연결함. 이처럼 작은 생활 문제를 앱 요구사항으로 바꿀 수 있음을 설명함.

시간 운용: 영상 약 15초, 설명 및 참여 약 105초. 입력 전문은 웹 교재에 제공함.

## 02. 셔틀버스 노선도를 살펴봄 / 2~4분

노선도를 사용할 때 필요한 질문은 정류장이 어디인지, 어느 노선에 속하는지, 어떤 자료를 기준으로 표시했는지임.

실제 화면에서 정류장과 노선을 확인함. 지도에 선이 그려졌다는 사실만으로 실제 운행 경로나 시간이 정확하다고 판단하지 않음.

AI에게는 기능뿐 아니라 사용할 자료도 지정해야 함. 제공되지 않은 운행 시간이나 위치를 만들지 않도록 요청문에 조건을 넣음.

시간 운용: 영상 약 13초, 설명 및 참여 약 107초. 입력 전문은 웹 교재에 제공함.

## 03. Codex로 첫 작업을 시작함 / 4~6분

Codex는 요청을 받아 작업 폴더의 파일을 만들거나 수정하고 도구로 결과를 확인하는 작업 흐름에 활용함. 일반 채팅의 설명과 실제 파일 생성은 구분함.

Windows 설치는 공식 안내를 출발점으로 삼음. 학교 계정, 이용 권한과 설치 환경은 교사가 수업 전에 확인함. 영상의 공식 화면과 실제 실행완료 기록 조회를 구분하여 설명함.

처음에는 새 실습 폴더에서 간단한 행사 안내 페이지를 요청함. 생성 파일 목록, 실제 페이지와 빠진 항목을 확인하도록 안내함.

시간 운용: 영상 약 31초, 설명 및 참여 약 89초. 입력 전문은 웹 교재에 제공함.

## 04. Claude Code로 파일을 수정함 / 6~8분

Claude Code도 프로젝트 폴더를 기준으로 파일을 읽고 수정하는 작업에 활용함. 이번 수업은 모델 성능 순위를 비교하는 과정이 아님.

기존 안내 페이지에서 제목 크기와 모바일 배치를 바꾸는 요청을 예로 듦. 행사 일시나 장소 같은 사실 정보는 유지하도록 명시함.

수정 완료 응답만 읽지 말고 바뀐 파일과 실제 화면을 확인함. 잘못 바뀐 부분이 있으면 그 부분을 구체적으로 지정해 다시 요청함.

시간 운용: 영상 약 30초, 설명 및 참여 약 90초. 입력 전문은 웹 교재에 제공함.

## 05. 요청에 필요한 조건을 담음 / 8~10분

게임 만들어줘라는 요청은 목적과 범위가 불분명함. 다섯 카드로 목적, 대상, 입력 자료, 필수 기능과 완료 기준을 나누어 설명함.

고등학생이 실습하고 원본 캐릭터 JPG를 사용한다는 조건을 넣음. 캐릭터 선택과 점프 같은 기능, 원본 보존과 동작 확인 같은 완료 조건을 추가함.

참여자에게 요청에 더할 조건 하나를 말하도록 안내함. 정답 맞히기보다 무엇을 확인할 수 있게 되었는지를 묻고 요청문에 연결함.

시간 운용: 영상 약 0초, 설명 및 참여 약 120초. 입력 전문은 웹 교재에 제공함.

## 06. Prompt Master로 요청을 다듬음 / 10~13분

Prompt Master는 특정 AI 도구에 입력할 요청문을 구성하는 스킬임. 처음부터 게임을 개발하는 실행과 프롬프트를 작성하는 요청을 구분함.

먼저 대상 도구를 Codex로 지정함. 목적, 환경, 제공 자료, 필수 기능과 검증 기준을 넣고 지금은 프롬프트만 작성하도록 범위를 제한함.

생성된 요청문에서 원본 JPG 보존, 캐릭터 선택, 이동과 충돌 확인 조건이 유지되었는지 살펴봄. 길고 복잡한 문장 자체를 좋은 프롬프트의 기준으로 삼지 않음.

영상의 프로젝트 범위 설치는 이전 실행 기록임. 현재 공용 원본과 Claude 연결 방식은 웹 교재의 shared-install 안내로 이어서 설명함.

시간 운용: 영상 약 28초, 설명 및 참여 약 152초. 입력 전문은 웹 교재에 제공함.

## 07. AI 확장 기능의 관계를 이해함 / 13~16분

작업대 왼쪽 노트북은 에이전트를 설명하는 모형임. 에이전트는 목표를 받고 필요한 도구를 사용하여 작업을 수행함. 실제 소프트웨어가 이 공간에 물리적으로 배치된다는 의미는 아님.

가운데 책과 체크리스트는 스킬을 뜻함. 스킬은 어떻게 작업할지에 관한 절차와 규칙을 제공함. 스킬이 모든 명령을 자동 실행하거나 성공을 보장하는 것은 아님.

오른쪽 서버와 연결선은 MCP를 통한 외부 도구 및 데이터 연결을 뜻함. 연결 가능한 도구가 있어도 인증과 권한, 실제 연결 상태를 확인해야 함.

플러그인은 관련 기능을 쉽게 배포하고 설치하도록 묶는 단위임. 에이전트, 절차, 연결과 배포를 서로 다른 역할로 이해하도록 정리함.

시간 운용: 영상 약 24초, 설명 및 참여 약 156초. 입력 전문은 웹 교재에 제공함.

## 08. 작업을 나누고 도구를 연결함 / 16~18분

자료 조사는 조사 작업으로, 코드는 점검 작업으로 나누어 맡기는 예시로 서브에이전트를 설명함. 작업별 범위와 결과를 정하고 주 에이전트가 결과를 종합함.

훅은 파일 수정 등 정해진 이벤트에서 등록한 검사를 실행하는 예로 설명함. 형식 검사가 실패할 수 있으며 모든 오류를 자동 해결한다고 설명하지 않음.

PLAYMCP 화면에서 도구 탐색과 연결의 출발점을 보여줌. 실제 도구 호출 성공과 화면 방문을 구분함. 공용 설치의 상세 명령은 짧은 수업 뒤에 웹 교재로 제공함.

시간 운용: 영상 약 9초, 설명 및 참여 약 111초. 입력 전문은 웹 교재에 제공함.

## 09. 게임의 기능과 규칙을 정함 / 18~20분

개발 전에 기능을 선택 화면, 이동, 점프, 충돌, 점수와 다시 시작으로 나눔. 각 기능을 확인할 방법을 함께 정함.

제공된 JPG 10종을 원본 그대로 선택 카드에 사용하는 실제 화면을 보여줌. 공식 캐릭터 전체를 도트 스프라이트로 변환했다고 설명하지 않음.

처음부터 많은 기능을 추가하기보다 선택에서 플레이까지 작은 흐름을 완성함. 캐릭터 ID가 유지되고 올바른 이미지가 표시되는지를 확인함.

시간 운용: 영상 약 0초, 설명 및 참여 약 120초. 입력 전문은 웹 교재에 제공함.

## 10. 캐릭터를 움직이고 장애물을 넘음 / 20~22분

실제 게임 영상에서 이동과 점프를 관찰함. 방향키 입력, 바닥 상태와 장애물 위치가 동작에 어떤 조건을 주는지 설명함.

3D 단면 영상은 점프와 충돌을 이해하도록 별도로 제작한 교육용 모델임. 실제 게임의 렌더링 결과나 제천시 공식 캐릭터의 3D 모델이 아님.

움직이는 화면과 규칙의 확인을 연결함. 장애물을 넘을 때와 겹칠 때, 점수가 바뀌는 때를 구분하고 다시 시작까지 확인함.

시간 운용: 영상 약 35초, 설명 및 참여 약 85초. 입력 전문은 웹 교재에 제공함.

## 11. 요청을 수정하고 결과를 확인함 / 22~24분

변경할 조건을 한 가지로 좁히면 원인과 결과를 비교하기 쉬움. 점프 높이만 바꾸고 장애물 간격은 유지하는 요청을 예로 듦.

슬라이드의 충돌 화면은 기존 실행 결과임. 현재 점프 높이 수정 예시는 후속 실습 요청이며 수정 전후 실험을 이미 수행했다고 설명하지 않음.

원본 파일을 보존하고 변경 설정, 이동, 충돌, 점수와 재시작을 다시 확인하도록 안내함. 단순히 오류가 없다는 응답과 실제 테스트 통과를 구분함.

시간 운용: 영상 약 0초, 설명 및 참여 약 120초. 입력 전문은 웹 교재에 제공함.

## 12. 실습 내용을 보고서로 정리함 / 24~26분

실습 기록을 보고서로 옮길 때 사용한 자료, 수행한 활동과 확인 결과를 먼저 모음. 실제 시행하지 않은 학생 실험과 학습 효과를 추가하지 않음.

HWPX 스킬의 공용 설치 위치와 문서 출력 폴더를 구분함. 양식을 읽고 제목, 표와 항목을 유지하여 새 결과 파일을 만드는 흐름을 설명함.

학생 보고서는 프로젝트 과정과 확인 결과를, 교사 기록은 운영 과정과 보완 사항을 정리하도록 예시를 나눔. 사실과 해석을 구분함.

시간 운용: 영상 약 0초, 설명 및 참여 약 120초. 입력 전문은 웹 교재에 제공함.

## 13. HWPX 양식으로 보고서를 작성함 / 26~28분

실제 기존 HWPX 보고서 생성 및 한글 열기 영상을 보여줌. 원본 양식을 유지하고 새 파일로 저장하는 요청의 조건을 확인함.

HWPX가 ZIP/XML 구조 검사를 통과해도 표, 글자와 쪽 구성이 적절한지는 실제 한글 화면에서 확인해야 함. 검사 수준을 나누어 설명함.

웹 교재에서 원본 양식과 학생용, 교사용 보고서 예시를 내려받을 수 있음을 안내함. 해당 예시는 기존 실행 자료이며 새로운 수업 성과를 주장하지 않음.

시간 운용: 영상 약 28초, 설명 및 참여 약 92초. 입력 전문은 웹 교재에 제공함.

## 14. 수업과 학습에 적용함 / 28~30분

교사는 수업자료와 활동지, 학생은 탐구 기록과 작은 앱, 프로젝트 보고서에 오늘 흐름을 적용할 수 있음을 정리함.

수업 활용 영상은 AI 생성 예시이며 실제 교사와 학생을 촬영한 자료가 아님을 화면 표시와 함께 안내함.

QR로 웹 교재를 열고 자신에게 필요한 후속 실습 한 가지를 고르도록 마무리함. 요청을 잘 쓰는 것과 결과를 직접 확인하는 것을 함께 기억하도록 정리함.

시간 운용: 영상 약 12초, 설명 및 참여 약 108초. 입력 전문은 웹 교재에 제공함.
