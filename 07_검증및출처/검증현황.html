화면 확보 상태

직접 접속한 공식 웹페이지와 두 도입 앱, 게임 선택·실행·점프·종료·재시작 화면을 캡처했다. 일부 브라우저 제어 중단이 있었으나 이후 새 요청에 따른 브라우저 작업에서 추가 게임 시험과 캡처를 확보했다. 모든 설치·로그인·에이전트 메뉴 화면을 확보한 것은 아니다. 미확보 화면을 가공 성공 화면으로 대체하지 않았다.

HWPX 페이지 이미지는 실제 한글에서 PDF로 내보낸 파일을 렌더한 것이다. 한글 앱 UI 전체를 촬영한 스크린샷은 아니다. 자료도판과 실제 화면 캡처는 파일 목록에서 구분했다.

이용 조건

제천시 페이지에 출처표시·상업적 이용금지·변경금지 조건이 표시되어 있었다. 제공 JPG는 바이트 그대로 복사했고 원본 격자 배경도 유지했다. 도트 스타일은 새로 작성한 배경·장애물에 적용했다. 별도 변형·상업 이용·공개 재배포 허락을 취득한 것은 아니다.

Anthropic 개인용 서비스는 18세 이상 조건을 확인했으므로 기본 고교 수업에서는 Claude Code를 교사 시연으로 안내했다. 계정 공유나 나이 우회 실습은 포함하지 않았다.
