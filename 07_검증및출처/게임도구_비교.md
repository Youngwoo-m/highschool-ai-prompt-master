# 게임용 스킬·플러그인 선정 기록

확인일 2026-11-10. `npx skills find phaser`에서 실제 후보를 확인하고 원본 저장소를 검토했다. 검색 당시 인기도는 변할 수 있어 선정의 단독 기준으로 쓰지 않았다.

|후보|원본|형태·목적|이번 적용|
|---|---|---|---|
|game-setup-and-config|[phaserjs/phaser](https://github.com/phaserjs/phaser)|Phaser 공식 스킬. Phaser 4 게임 설정·렌더러·pixelArt·스케일 설정|선정·프로젝트 설치 성공. 설정 지침을 읽고 예제에 적용|
|phaser-core|[gamedev-skills/awesome-gamedev-agent-skills](https://github.com/gamedev-skills/awesome-gamedev-agent-skills)|커뮤니티 엔진별 스킬 모음. 검색 후보로 확인|추가 설치하지 않음. 개별 스킬 원문·의존성·라이선스 확인 후 대안으로 사용|
|game-creator|[PlayableIntelligence/game-creator](https://github.com/PlayableIntelligence/game-creator)|Claude 플러그인. 2D·3D 게임 제작 워크플로|기본 수업의 설치 범위를 줄이기 위해 미설치. 다른 제품 자동 호환으로 설명하지 않음|

선정 이유: 공식 소스와 버전 범위가 명확하고 첫 게임의 설정을 다루므로 고등학교 기초 수업에서 설명하기 쉽다. 스킬과 엔진을 구분하여 설치했다. 엔진은 npm 공식 phaser 패키지 4.2.1 배포본을 vendor에 저장하고 라이선스를 함께 보관했다. 버전·배포 URL은 vendor/version.json에서 확인한다.
